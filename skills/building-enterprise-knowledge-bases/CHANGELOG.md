# Changelog

## 2.0.1 — 发布一致性修订

- 统一事实状态受控词为 `已确认 / 待核验 / 历史 / 失效 / 版本冲突 / 缺失 / 不适用`，并明确 `未发现` 仅用于查询/匹配结果。
- 统一 `bid-matching-contract.md` 与 `bid-requirement-schema.csv` 的接口字段，采用 `time_start / time_end / parent_group / logic`。
- 企业业绩与个人业绩台账改为“每个数值指标独立单位字段”，消除单一 `规模单位` 的量纲歧义。
- 初始化器与结构校验器版本更新至 V2.0.1，并补充关键表头回归校验。
- 补充发布一致性测试，避免文档、模板与脚本再次漂移。

## 2.0.0 — 投标匹配就绪

- 保留 V1.0 七大一级目录和唯一正式归档原则。
- 新增 `construction-bidding` 初始化/校验档案。
- 新增投标事实索引，以及企业资质、投标人员、企业业绩、个人业绩、信用奖项、财务税务保险、设备资源、技术方案九类专业台账。
- 企业业绩改为可按工程类别、金额、面积、长度、高度、跨度、容量和日期等字段筛选。
- 新增原子事实模型：原始值、标准值、单位、来源定位、核验时间。
- 新增 A/B/C/D 证据完整度与投标匹配闸门。
- 明确企业业绩与个人业绩分离、经营范围不等于专业资质、待核验不得判满足。
- 新增 `bid-matching-contract.md`，定义解标条件与知识库之间的输入/输出协议。
- 新增投标条件、匹配结果和匹配报告模板。
- 扩充 eval 场景与自动化回归测试。
